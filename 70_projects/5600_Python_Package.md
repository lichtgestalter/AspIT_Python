# Projekt Python Package

## Opgave

Lær, hvordan man skriver og udgiver en Python-pakke, så andre kan downloade og 
bruge den, fx via `pip install`. 

## Kom i gang

Gennemarbejd dette 
[tutorial](https://packaging.python.org/en/latest/tutorials/packaging-projects/).

Brug `setuptools` som build backend.

## Skriv din egen pakke

Find et emne, der interesserer dig, og som du kunne skrive kode til, som andre 
kan bruge i deres Python-kode. 

Skriv og udgiv koden og dokumentationen til denne Python-pakke.
